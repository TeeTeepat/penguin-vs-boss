# A simple web app that tech the student how remember the mutiply table by gamiply it.

## idea
* this game have 4 mode like minecraft(my student love it) from can open the mutiply table with no heart reset to can not and with heart reset.
* the app must observe what student got wrong and give it to him again and again so he not gonna for get it.
* the game start with 5 heart(star) every time student got the answer right the heart - 1 when student win 5 time in a row(or maybe more up the the level) their win!
